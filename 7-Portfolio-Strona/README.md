# Szablon strony portfolio

Prosty, jednostronicowy szablon portfolio dla freelancera (HTML, CSS, Vanilla JS). Wcześniejsza wersja strony głównej tego repozytorium, zachowana jako szablon do personalizacji.

## Sekcje

- Hero z nagłówkiem i przyciskami CTA
- Portfolio (karty projektów z linkami do dem)
- Usługi
- Cennik
- Kontakt (formularz + dane kontaktowe)

## Personalizacja

Wszystkie dane zastępcze (`TwojeImię.dev`, `kontakt@twojeimie.pl`, `+48 123 456 789`, linki social) znajdują się w `index.html`. Kolory zdefiniowane są jako zmienne CSS na początku `style.css`.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Linki do projektów prowadzą do folderów nadrzędnych tego repozytorium.
